# Classes-Java

Repositório com classes Java criadas do zero para estudar para a prova de Técnicas de Programação no Cotuca (Colégio Técnico de Campinas), com foco em Programação Orientada a Objetos.

## 📂 Estrutura do repositório

### [`Classes-Básicas`](./Classes-Básicas)
Exercícios de classes para praticar os fundamentos de POO, como construtores, validações e os métodos `toString`, `equals`, `hashCode` e `compareTo`.

Exemplos: `Agenda`, `Aluno`, `Angulo`, `Biblioteca`, `Circulo`, `Complexo`, `ContaBancaria`, `Data`, `Disciplina`, `Estoque`, `Funcionario`, `Horario`, `Livro`, `MediasFinais`, `Pedido`, `Retangulo`, `Triangulo` e `Turma`.

### [`JogoForca`](./JogoForca)
Implementação completa do jogo da forca, com várias classes trabalhando juntas. Tem README próprio com a descrição e as instruções para executar.

## 🛠️ Tecnologias utilizadas

- Java

## ▶️ Como executar

1. Clone este repositório:
   ```bash
   git clone https://github.com/devJonas07/Classes-Java.git
   ```
2. Entre na pasta que quiser testar (`Classes-Básicas` ou `JogoForca`).
3. Compile e execute as classes pela sua IDE ou pelo terminal (`javac *.java`).
